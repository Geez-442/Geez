Thank you for considering contributing to ZETS.

This is a research project led by Gerald Gwashavanhu (r226871T). Before contributing:

- Open an issue describing the change and obtain supervisor or maintainer approval for major additions.
- Keep changes small and scoped to a single purpose (one feature/fix per PR).
- Include tests for any logic changes. For UI changes include screenshots and accessibility notes.
- Preserve the audit trail: describe all decisions in the PR description and link to relevant sections in PROJECT_BLUEPRINT.md.

Code style
- Use TypeScript. Follow ESLint + Prettier conventions (configs will be added in Sprint 1).

Licensing
- Contributions are accepted under the project MIT license. By opening a PR you agree to license your contribution under the project license.

Security
- Do not commit secrets or private keys. Use the .env.example as guidance and commit only example values.
